# euNICE Apparel & Branding — Website

A modern, single-page marketing site for **euNICE Apparel & Branding**, a custom printing and
branding business. It covers the business's story, services (custom t-shirts, caps, mugs,
flasks, pens, hand fans, frames and other promotional items), a work gallery, and a contact
section with direct Call and WhatsApp actions.

## Tech stack

- [TanStack Start](https://tanstack.com/start) (React 19 + TanStack Router) on Vite 7
- Tailwind CSS 4 with a custom gold / ink / paper (black & white) theme
- lucide-react icons
- Netlify Forms for the contact form
- Deployed on Netlify

## Running locally

```bash
npm install
npm run dev
```

The dev server runs on `http://localhost:3000`. To exercise the contact form with real Netlify
Forms behaviour (form detection only happens at build time), test it on a deploy preview instead
of the local dev server.
